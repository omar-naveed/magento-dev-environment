# Magento Dev Environment

A portfolio project documenting a Magento Open Source local development
setup and the engineering workflow used to build against it — sample data
only, no real store or customer content.

## Stack

- Magento Open Source 2.4.9
- DDEV for local environment orchestration
- PHPStorm, n98-magerun2, TablePlus/DBeaver

## Status

Environment scaffolding in progress. See `docs/` for setup notes and
decisions.
